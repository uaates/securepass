# 🔐 SecurePass

SecurePass, PySide6 (Qt) ile geliştirilmiş, **offline**, **şifreli** ve **çok kullanıcılı** bir parola yöneticisidir.

## ✨ Özellikler
- 🖥️ Modern Qt (PySide6) arayüz
- 🔐 Güçlü parola üretimi
- 👤 Kullanıcı bazlı kayıtlar
- 📊 Kayıt listeleme (QTableView)
- ✏️ Düzenleme / 🗑 Silme
- 🔒 Fernet ile şifreleme
- 🌐 Tamamen offline

## 🛠 Kullanılan Teknolojiler
- Python 3
- PySide6 (Qt)
- Cryptography (Fernet)
- PyInstaller

## 🚀 Kurulum
```bash
pip install pyside6 cryptography pyperclip
python main.py
